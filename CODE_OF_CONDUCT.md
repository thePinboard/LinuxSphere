# Code of conduct

Our community aims to be a respectful, technical and inclusive place for discussing LinuxSphere VE and DroidSphere integration.

**Expected:** constructive critique, reproducible evidence, patience with newcomers, respect for contributors' time, and privacy-conscious bug reports.

**Unacceptable:** harassment, insults, threats, discriminatory conduct, doxxing, intentional disclosure of credentials or private infrastructure details, and unsolicited promotion unrelated to the project.

Maintainers may edit or remove inappropriate material, lock discussions or restrict participation. If an issue involves personal safety or private information, use a private channel offered by the repository owner rather than posting sensitive details publicly.

This local code of conduct defines project expectations; it is not a copy of a third-party template.
