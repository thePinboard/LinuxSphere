# Support and questions

- **Usage questions:** first read [README.md](README.md), [installation](docs/en/INSTALLATION.md) and [FAQ](docs/en/FAQ.md).
- **Reproducible bugs:** open a GitHub issue with the provided template and sanitized logs.
- **Feature suggestions:** use the feature-request issue template and explain the use case.
- **Vulnerabilities:** use [SECURITY.md](SECURITY.md), not a public issue.

No paid support, uptime commitment or production SLA is implied for the development preview. A public support email has not been declared.
